sector-research · architecture map

Personal stock-research app. Discovery (FMP fundamentals + X social signal + insider/congress modifiers) feeds a 6-phase LangGraph due-diligence pipeline with citations on every data point. Post-thesis surfaces (Today briefing, status board, unified calendar, material events, workspace loop, financial model, peer comp, outcome tracker, trade journal) close the feedback loop.

LangGraph pipeline · phases

PHASE 1
quick_screen
Haiku
Structural pre-filter — market cap, sector, industry, volatility.
→
PHASE 2
deep_dive
Sonnet
9 categories in parallel. Fetches 10 FMP endpoints + filing sections + XBRL facts + counterparty context + FRED macro.
→
PHASE 3
targeted_followup
Haiku
Retry for priority-1 auto-answerable questions from deep-dive.
→
PHASE 4
thesis_construction
Sonnet
Pillars, bull/bear, catalysts, kill criteria. Receives quick-screen + deep-dive summary with no-restate framing.
→
PHASE 5
risk_stress_test
Sonnet
Scenario stress test. Optional loop back to deep_dive if loop_count ≤ 2.
⇢
PHASE 6
position_monitor
Haiku
Manual: POST /api/runs/{id}/advance with action='approve'. Creates verdict_outcomes row.

Invariants & gotchas ⚠ read before touching code

uvicorn_cwd
Always launch uvicorn from PROJECT ROOT — never from backend/
Why: backend uses absolute imports rooted at project root (backend.app.*). Running from backend/ breaks every import. Tests + migrations also need PYTHONPATH or pip install -e ..
env_file_path
.env lives at PROJECT ROOT and stays there
Why: backend/app/config.py hard-codes env_file='../../.env' relative to backend/app/. Moving it breaks Settings load. Required keys: FMP_API_KEY · X_BEARER_TOKEN · ANTHROPIC_API_KEY · DATABASE_URL · DATABASE_URL_SYNC · SEC_USER_AGENT.
ticker_uppercase
Every model/filing/earnings endpoint normalizes ticker = ticker.upper() at entry
Why: ticker_models, ticker_model_drafts, research_runs, earnings_prints all store tickers upper-case. Skipping breaks lookups + risks duplicate-identity drafts.
async_session_commit
async_session() does NOT autocommit — explicit await db.commit() required
Why: expire_on_commit=False but no autocommit. Forgetting this means nothing persists silently. Applies to services/fanout.py per-ticker stages and services/model_baseline.initialize_or_get_model and any service that opens its own session.
fmp_client_singleton
Use app.state.fmp via request.app.state.fmp — do NOT instantiate FMPClient() in endpoints
Why: the singleton from lifespan owns the rate limiter and shared session. Example: models_api.get_reverse_dcf uses request.app.state.fmp for the live price default.
pipeline_routing_single_source
Pipeline phase routing has ONE source of truth: PHASE_SEQUENCE / next_phase() in graph/pipeline.py; services/pipeline.py::_next_phase delegates
Why: PR #42 collapsed the former dual-truth; backend/tests/test_phase_routing.py pins the contract.
sse_event_sync
Python pipeline._emit calls and the TypeScript SSEEvent discriminated union MUST stay in sync
Why: SSEEvent in frontend/lib/api/pipeline.ts is a discriminated union. New event types added on the Python side won't be typed on the frontend.
citation_three_shapes
Three Citation shapes exist — keep them aligned
Citation (dataclass, models/citation.py): used for return tuples (data, Citation) from data clients · CitationRecord (ORM persisted form, same file, citations table) · StateCitation (graph/state.py): JSON-serializable, lives inside ResearchState.state JSONB with ISO-string timestamp. Adding a new data source = preserve the (data, Citation) tuple convention.
score_keys_normalization
Use scoreKeys.ts::normalizeScoreKeys at every backend → frontend boundary
Why: report API returns display-name keys ("Macro & Regime") while ScoreBar / radar / chip components expect snake_case. Skipping silently produces all-em-dash ScoreBar.
score_palette
Use scoreColors.ts for score-tier coloring; use heatmapColors.ts for sensitivity grids
Why: local if/else palettes at 40/50/70 cluster everything 40-60 into a single amber band. Diverging heatmap palette is for grid coloring, not score tiers — don't swap them.
next16_breaking
Next.js 16 has breaking changes. Read node_modules/next/dist/docs/ before editing routing, middleware, route handlers, or Server Component APIs
Why: training-data conventions for middleware.ts, route-handler shapes, and caching primitives don't match Next 16.
cell_path_value_object
cell_path wire format is owned by typed CellPath union on both sides
Shapes: DriverPath | StatementCellPath | AssumptionPath. AssumptionPath only accepts ModelCell-shaped keys (discount_rate, terminal_multiple, perpetuity_growth, tax_rate). Categorical assumptions (terminal_method, plug_priority) intentionally not editable through PUT /draft.
concentration_via_narrative_not_xbrl
Customer concentration is in relationships (with unnamed=true), NOT in xbrl_facts
Why: ConcentrationRiskPercentage1 is always dimensionally disclosed and the SEC companyfacts API only exposes un-dimensioned parent facts. The xbrl_facts table covers RPO, debt maturity, credit only.
localhost_ipv6_collision
Pin NEXT_PUBLIC_API_URL to http://127.0.0.1:8000 if Docker is running
Why: Docker dashboard-api-1 can steal IPv6 localhost:8000 from uvicorn.
print_view_data_attr
Tag new sticky UI (nav, action buttons, modals) with data-print-hide="true"
Why: @media print in app/globals.css hides any element with that attribute and forces opaque surfaces — keeps chrome out of the PDF.
section_dual_panel_pattern
DataRichSection + MixedSection render AICompanionPanel twice — once with section='summary' inside the chart grid, once with section='analysis' as a full-width block below
Why: prevents the analysis paragraph from making the right column 2× taller than the charts and leaving empty whitespace on the left. QualitativeCard renders it without a section prop (single-column).
report_api_phases_deep_dive_shape
phases.deep_dive in the report API is { categories: Record<str, CategoryOutput>, curated_financials: CuratedFinancials | null } — NOT a flat record
Why: consumed by every frontend page that reads /api/runs/{id}/report.
no_pytest
Tests run under Python's stdlib unittest — python -m unittest backend.tests.<module> from project root with venv active
Why: no pytest, no coverage harness. Don't introduce pytest unless intentionally migrating.
fanout_in_memory
FanoutStatus is in-memory only — does NOT survive backend restart
Why: acceptable for personal tool. If you persist it later, update FanoutService accordingly. Also: force=True on fan-out only affects the EXTRACT stage; resolve already skips rows with resolved_to_cik IS NOT NULL.
prospectus_synthetic_ticker
Prospectus (S-1) issuers are written into filings.ticker / relationships.ticker under a synthetic_ticker — proposed_ticker if disclosed, else uppercase-alphanumeric slug of issuer_name truncated to 16 chars
Why: lets the entire existing 5-phase EDGAR pipeline (section extraction, relationship extraction, counterparty resolution, supply-chain graph) work unchanged on pre-IPO issuers. The derived value is a @property on ProspectusReport — don't re-normalize at endpoint boundary.
prospectus_score_thresholds
Prospectus CategoryCard score color thresholds are IPO-specific — do NOT replace with scoreColors.ts (equity 40/55/70 tiers)
Why: IPO scoring uses a different rubric (0-30 disqualifying, 31-55 uncertain, 56-75 typical, 76-100 standout) defined in graph/prospectus_prompts.py::PROSPECTUS_SYSTEM. Equity tiers would map IPO scores wrong.
route_ordering_footguns
Two literal routes must stay declared BEFORE their sibling path-param routes: /api/peers/compare before /api/peers/{ticker}, and /api/catalysts/calendar before /api/catalysts/{catalyst_id}
Why: "compare" parses as a valid ticker and "calendar" as a path param — declared later, the literal routes become unreachable. Both pinned by test.
commit_free_services
services/journal.py and services/peer_sets.py write WITHOUT committing — callers own the session
Why: API routes commit; the workspace differentiation step composes peers_for_ticker inside its own transaction. Adding a commit inside these services would break callers that batch multiple writes.
workspace_step_order
Workspace loop execution order is update_refresh → research → validation → challenge → differentiation — pinned by STEP_NAMES in services/workspace_steps.py
Why: validation re-runs the reverse-DCF against the post-Step-1 model version, and challenge consumes Step 1's model deltas. Docs that list challenge before validation are wrong.
sse_replay_semantics
All three SSE services fan out to multiple subscriber queues per run via a shared EventBroker (services/event_broker.py, PR #63). PipelineService has NO replay; WorkspaceService and ProspectusService keep a per-run replay buffer — late subscribers get a full replay on event_stream() entry.
Why: PR #63 unified the three services' previously hand-rolled fan-out/replay plumbing onto EventBroker, preserving each service's pre-existing replay policy (pipeline off since PR #42; workspace/prospectus on since PR #42/#46). Don't assume pipeline late-joiners see early events.
theme_token_classes
Frontend colors use CSS-variable token classes only (bg-[var(--surface)], text-[var(--text-muted)], …) — no slate-*/gray-*/zinc-* palette classes
Why: B3 phase 4 (PR #53) migrated all surfaces to a global token palette (tokens in app/globals.css); raw palette classes drift from the theme. Guard documented in frontend/AGENTS.md.
questions_snooze_predicate
Any query for "open" questions must reuse the shared snooze-exclusion predicate in services/questions.py
Why: PR #51 added bulk snooze (snoozed_until). A consumer filtering status == 'open' directly would resurface snoozed questions before expiry.
discovery_card_manual_serializer
CompanySignalCard.to_dict() (services/discovery.py) is the canonical wire serializer — a recursive dataclasses.fields() walk via _wire_value that special-cases Citation to the 5 frontend keys. api/discovery.py::_card_to_dict is now a thin shim, kept only because the regression test imports it by name.
Why: PR #62 inverted the old hand-enumerated _card_to_dict, which silently dropped any unmapped field (both the congress chip, PR #57, and the centrality chip, PR #59, shipped invisible that way). A new scalar or nested snapshot field now reaches the frontend automatically — you opt one OUT by excluding it in _wire_value, not in by remembering to add it. All three snapshot keys (insider/congress/centrality) are pinned by test_discovery_card_serialization.py.
event_broker_zero_config
Each SSE-emitting service's terminal_types / replay / heartbeat_seconds / queue_maxsize are fixed once at EventBroker construction: pipeline — terminal {complete, error}, replay=False, heartbeat=30s; workspace — terminal {workspace_run_complete, workspace_run_failed}, replay=True; prospectus — terminal {prospectus_complete, prospectus_failed}, replay=True; queue_maxsize=500 for all three (QueueFull drops the event for that one subscriber, never blocks the others).
Why: PR #63 consolidated three previously hand-rolled SSE implementations behind one class; these config values ARE the behavioral contract now. Pinned by backend/tests/test_sse_service_config.py (6 tests) and backend/tests/test_event_broker.py (14 tests, replaced the deleted test_sse_streams.py).
model_vocab_parity
frontend/lib/modelVocab.ts (PNL_LINES, BS_LINES, CF_LINES, DRIVER_KEYS) must stay identical in membership AND order to the backend registries in backend/app/models/model_state.py (LINE_ITEMS_PNL/BS/CF, DRIVER_KEYS).
Why: ForecastGrid/DriverPanel render one row per frontend entry, then look the value up by key — a mismatched key silently produces an empty/absent row rather than an error. modelVocab.test.mts regex-scrapes model_state.py at test time so drift fails CI instead of shipping a blank column.
