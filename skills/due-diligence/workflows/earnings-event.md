## When to Use

- **Pre-earnings:** 1-2 days before the earnings release for any current holding or high-priority watchlist name
- **Post-earnings:** Within 24 hours after the earnings release — delay degrades the quality of the transcript analysis and price reaction read
- **Guidance revision:** A company issues a pre-announcement (guide-up or guide-down) outside the normal earnings cycle — run the post-earnings phase immediately

This workflow is designed to prevent the most common earnings mistakes: (1) reacting to headlines rather than the actual scorecard, and (2) making position decisions in real-time during market hours without a pre-committed framework.

**Pre-earnings work is mandatory.** Do not run the post-earnings phase without completing pre-earnings — you need your expectations documented before seeing the results.

## Process

---

## Pre-Earnings Phase (45 min)

### Pre-Step 1 — Expectations Baseline (15 min)

Establish what the market expects and, separately, what YOU expect. These are often different, and the gap between your expectation and the actual result matters more than the gap between actual and consensus.

**Skills used:**
- `categories/03-growth-earnings/analyst-expectations` (pull current consensus for revenue, EPS, and key segment metrics)
- `categories/03-growth-earnings/guidance-analysis` (review last quarter's guidance — what did management say they would deliver?)

**Document the following before seeing any results:**

| Metric | Last Quarter Actual | Management Guide | Consensus Estimate | YOUR Estimate | Reasoning for Deviation |
|--------|--------------------|-----------------|--------------------|---------------|------------------------|
| Revenue | | | | | |
| EPS (adjusted) | | | | | |
| Gross margin | | | | | |
| Operating margin | | | | | |
| [Key segment 1] | | | | | |
| [Key segment 2] | | | | | |
| FCF / Operating cash flow | | | | | |
| Full-year guidance (revenue) | | | | | |
| Full-year guidance (EPS) | | | | | |

**Why your estimate matters:** If you expect $1.20 EPS and consensus is $1.10, a $1.15 result is a MISS relative to your view even though it beats consensus. Price often reacts to the spread vs. the highest credible estimate (the "whisper number"), not just consensus.

**Key question to answer:** What is the single metric that will matter most to investors this quarter? Name it. Write down your threshold for what constitutes a beat vs. miss on that metric.

---

### Pre-Step 2 — Key Metrics Scorecard (15 min)

Build the 5-8 metric scorecard you will use to evaluate the results the moment they are released. Do not add metrics after you see results — that is post-hoc rationalization.

**Skills used:**
- `categories/03-growth-earnings/revenue-driver-decomposition` (identify which revenue segments and drivers are most material this quarter)
- `categories/02-financial-health/cash-flow-quality` (identify which earnings quality metrics to watch for — accruals, working capital, deferred revenue changes)

**Scorecard construction:**

Choose 5-8 metrics that are:
- Quantitatively measurable (not "management tone")
- Available in the press release or 8-K (not requiring deep analysis of the full 10-Q)
- Thesis-relevant (they affect your bull, base, or bear case probability)

| # | Metric | My Threshold for BEAT | My Threshold for IN-LINE | My Threshold for MISS | Why It Matters |
|---|--------|----------------------|--------------------------|----------------------|----------------|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |
| 5 | | | | | |
| 6 (optional) | | | | | |
| 7 (optional) | | | | | |
| 8 (optional) | | | | | |

**Earnings quality flags to watch:**
- Receivables growing faster than revenue (channel stuffing risk)
- Deferred revenue declining (future revenue being pulled forward)
- Days Sales Outstanding expanding (collection pressure)
- Non-GAAP adjustments expanding vs. prior year (quality of earnings declining)
- Large restructuring or one-time charges (may be recurring if pattern-based)

---

### Pre-Step 3 — Scenario Planning with Pre-Committed Actions (15 min)

Define the three scenarios and — critically — your pre-committed response to each BEFORE you see the results. Decisions made under the pressure of a live market reaction are worse than decisions made in advance with clear heads.

**Three scenarios:**

**Beat + Raise (Positive Surprise)**
- Definition: 4+ metrics score BEAT, AND full-year guidance is raised
- Thesis implication: Bull case probability increases; catalyst may have fired partially
- Pre-committed action: [Choose one — ADD to position at market open / HOLD and reassess sizing / HOLD and watch for price to digest before adding]
- Maximum add size: [% of current position]
- Condition to NOT add despite beat+raise: [e.g., valuation already at bull case target]

**In-Line (No Surprise)**
- Definition: 3-4 metrics IN-LINE, guidance maintained within prior range, no major positive or negative surprises
- Thesis implication: No change to probability weights; neither confirms nor denies the thesis
- Pre-committed action: [Choose one — HOLD with no change / HOLD and use any price weakness to add at planned levels]

**Miss + Lower (Negative Surprise)**
- Definition: 3+ metrics score MISS, OR full-year guidance is reduced
- Thesis implication: Bear case probability increases; assess severity vs. invalidation threshold
- Pre-committed action: [Choose one — TRIM to defined size / EXIT full position / HOLD if miss is clearly non-recurring with specific reasoning]
- Invalidation threshold: [The specific miss severity that triggers full exit regardless of market price — e.g., "revenue miss > 5% AND guidance cut > 10% triggers exit"]

**Write these actions down before the earnings release.** You are not allowed to change them based on the results. If the results create ambiguity (e.g., beat on revenue but miss on margin), apply the scorecard: count BEAT / IN-LINE / MISS scores and let the majority determine the scenario.

## Post-Earnings Phase (30 min)

### Post-Step 1 — Results vs. Scorecard (10 min)

Score the results against the pre-earnings scorecard before reading any analyst commentary, news articles, or social media reaction. Forming your own view first is essential — external framing creates anchoring bias.

**Skills used:**
- `categories/02-financial-health` (data validation — verify numbers against the 8-K or press release, NOT financial news headlines, which frequently contain errors)

**Complete the scorecard:**

| # | Metric | Your Threshold | Actual Result | Score |
|---|--------|---------------|---------------|-------|
| 1 | | | | BEAT / IN-LINE / MISS |
| 2 | | | | BEAT / IN-LINE / MISS |
| 3 | | | | BEAT / IN-LINE / MISS |
| 4 | | | | BEAT / IN-LINE / MISS |
| 5 | | | | BEAT / IN-LINE / MISS |
| ... | | | | |

**Scorecard summary:**
- BEAT count: [#]
- IN-LINE count: [#]
- MISS count: [#]
- Guidance: RAISED / MAINTAINED / LOWERED / WITHDRAWN
- Scenario triggered: BEAT+RAISE / IN-LINE / MISS+LOWER

**Data validation checklist:**
- [ ] Numbers verified against 8-K or earnings press release (not headline)
- [ ] Non-GAAP to GAAP bridge reviewed — are adjustments larger or smaller than prior quarters?
- [ ] Any earnings quality flags from Pre-Step 2 triggered? (receivables growth, deferred revenue change, DSO)
- [ ] Share count change vs. prior quarter (buybacks or dilution affecting EPS)

**Apply your pre-committed action from Pre-Step 3.** Do not negotiate with yourself at this point. The pre-commitment exists precisely for this moment.

---

### Post-Step 2 — Transcript Analysis (10 min)

The press release tells you what happened. The earnings call transcript tells you what management thinks is happening and what is coming. These are different things.

**Skills used:**
- `categories/03-growth-earnings/guidance-analysis` (updated full-year and next-quarter guidance — any changes in tone, specificity, or confidence vs. last quarter?)

**Listen to or read the Q&A section. Document:**

1. **Updated guidance** — Exact numbers or ranges provided. Any change in language (e.g., "comfortable with consensus" vs. prior "expect to be at the high end")

2. **New risks or opportunities mentioned** — Any first mention of a new competitive threat, regulatory development, product delay, or market opportunity. First mentions in earnings calls often precede multiple quarters of impact.

3. **Capital allocation changes** — Any new buyback authorization, dividend change, acquisition mention, or capex revision. Record exact dollar amounts and management's stated rationale.

4. **Management tone assessment** — On a 5-point scale:
   - 5: Highly confident, specific, forward-looking with detail
   - 4: Confident, on-script, no major hedging
   - 3: Neutral, cautious language increased, more "we'll see" qualifications
   - 2: Defensive, deflecting specific questions, increased hedging
   - 1: Evasive, refusing to give specifics on prior guidance, visible stress

5. **Analyst questions that management dodged** — Note any questions that were answered with generalities or deflected entirely. These often point to the most important issues.

---

### Post-Step 3 — Thesis Update (10 min)

With the scorecard scored and the transcript analyzed, update the thesis probability weights and determine whether the investment case is intact.

**Skills used:**
- `categories/10-thesis-construction/evidence-grounding` (does the new evidence support or contradict prior thesis claims?)

**Thesis status assessment:**

Answer these questions in sequence:

1. **Did any catalyst fire?** (from your pre-earnings catalyst list)
   - If yes: update catalyst status and adjust probability weights accordingly
   - If no: note whether the timeline is still intact

2. **Were any invalidation conditions triggered?**
   - If yes: EXIT regardless of price. The pre-committed invalidation exists precisely to override emotional anchoring to a position.
   - If no: proceed to the next question

3. **Did any new risk emerge that was not in the original thesis?**
   - If yes: run `categories/08-risk-assessment/thesis-risk-mapping` on the new risk before finalizing thesis status
   - If no: proceed

4. **Revised probability weights:**

| Scenario | Prior Weight | New Weight | Reasoning for Change |
|----------|-------------|------------|---------------------|
| Bull case | X% | Y% | |
| Base case | X% | Y% | |
| Bear case | X% | Y% | |

5. **Thesis status — assign one:**
   - **CONFIRMED** — Results and transcript strengthen the thesis; catalysts intact; no new material risks
   - **WEAKENED** — One or more thesis assumptions are under pressure but thesis is not yet broken; define specific restore condition or begin planning exit
   - **INVALIDATED** — Core thesis assumption proven wrong; begin exit process per pre-committed action

**If WEAKENED:** Define the restore condition — the specific evidence that would return thesis status to CONFIRMED. If no restore condition is definable within 2 quarters, the thesis is effectively broken and should be classified INVALIDATED.

**Next review trigger:** Set the next thesis-review date (quarterly minimum; sooner if a specific catalyst is expected within 90 days).

---

## Output

**Required deliverables:**

1. **Pre-earnings scorecard** — completed table with your estimates vs. consensus, analyst guidance review, 5-8 metric scorecard, and pre-committed scenario actions

2. **Post-earnings actuals** — completed scorecard with BEAT / IN-LINE / MISS scores, scenario triggered, data validation checklist, and pre-committed action taken (or documented rationale if action was modified)

3. **Transcript notes** — updated guidance, new risks/opportunities, capital allocation changes, management tone score (1-5), and flagged deflected questions

4. **Thesis status** — CONFIRMED / WEAKENED / INVALIDATED with updated probability weights, reasoning, and next review trigger date

5. **Action taken** — specific position change executed (or HOLD with no change) and exact rationale referencing the pre-committed scenario from Pre-Step 3
